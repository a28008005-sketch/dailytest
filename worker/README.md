# 웨일리 보카 로그인 — 서버(워커) 쪽 변경

앱(`voca/index.html`)은 이제 **부모님 휴대폰 번호 뒤 4자리**로 로그인합니다.
학원 워커 `hello-world.a28008005.workers.dev` 의 `POST /api/voca/login` 도 같은 규칙으로 바꿔야 실제로 들어가집니다.
워커 원본은 이 저장소에 없어서, 바꿀 부분만 `voca-login.js` 에 함수로 만들어 두었습니다.

- `findStudentByPhone4(명부, 앱이 보낸 값)` — 4자리로 학생을 찾습니다. 형제처럼 여러 명이면 이름 목록(`choices`)을 돌려줍니다.
- 로그인에 성공하면 응답의 `code` 에 **그 학생의 기존 학습코드**를 넣어 주세요. 앱은 그 값으로 진도를 저장하므로 지금까지의 진도가 그대로 이어지고, 형제끼리 진도가 섞이지 않습니다.
- 나중에 만들 출결 앱도 같은 `last4()` 를 쓰면 출결 번호와 단어장 번호가 하나로 맞춰집니다.

확인: `node worker/voca-login.test.mjs`
