# 학원 워커 (hello-world.a28008005.workers.dev)

`hello-world.js` 는 클라우드플레어에 올라가 있는 학원 워커의 전체 코드입니다.
대시보드 화면, 노션 읽기·쓰기, 웨일리 보카 앱의 로그인·진도 저장·성적 기록을 맡습니다.

## 보카 로그인 — 부모님 휴대폰 뒤 4자리

- 아이가 4자리를 누르면 **원생관리 홈페이지 학생 정보의 '학부모 연락처'** 뒤 4자리로 학생을 찾습니다.
  (워커에 `SUPABASE_SERVICE_KEY`가 있어야 합니다. 아래 '처음 한 번' 참고)
  한 칸에 `010-…, 010-…`처럼 두 번호를 적어도 둘 다 됩니다. 퇴원생은 들어오지 못합니다.
- 원생관리에만 있는 학생은 명부에 아무것도 적지 않고, 학생 번호에서 늘 같은 코드(W로 시작)를 만들어 진도를 저장합니다.
  같은 이름이 노션 명부에도 있고 단어장코드가 있으면 그 코드를 그대로 써서 예전 진도가 이어집니다.
- 원생관리에 없는 학생은 예전처럼 노션 학생 명부의 **학부모 연락처 뒤 4자리**로 찾습니다.
  칸 이름에 학부모·부모·보호자가 들어간 전화번호(또는 글자) 칸을 읽습니다.
- 형제처럼 여러 명이 찾아지면 이름 목록을 돌려주고, 앱이 이름을 고르게 합니다.
- 로그인되면 그 학생의 **단어장코드**를 돌려줍니다. 앱은 이 코드로 진도를 저장합니다.
  코드가 없는 학생은 처음 들어올 때 자동으로 만들어 명부에 적습니다.
- 예전 단어장코드로 들어오는 것도 그대로 됩니다.

## 보카 성적 → 원생관리 '단어 학습' 화면

- 아이가 하루치를 끝내면 성적이 이 워커로 옵니다. 워커는 그 성적을
  ① 노션(이 대시보드의 과제 탭)과 ② 원생관리 홈페이지의 학원 클라우드(Supabase) 두 곳에 넣습니다.
- 원생관리 쪽은 **학생 이름이 똑같아야** 이어집니다. (앞뒤 빈칸은 무시, 동명이인이면 넣지 않음)
- 같은 학생이 같은 레벨·일차를 다시 풀면 새 줄이 아니라 덮어씁니다.
- 공부하는 동안에도 단계가 바뀔 때와 5문제마다 진행 보고(`status: in-progress`)가 옵니다.
  이건 **원생관리에만** 넣고(노션 수행률·성취률에는 하루치를 끝낸 성적만), 같은 줄이
  '학습 중' → '완료' 또는 '중간에 멈춤'으로 바뀝니다. 늦게 온 '학습 중'은 오늘 끝난 기록을 덮지 않습니다(`already-done`).
- 한쪽이 고장 나도 다른 쪽은 그대로 들어갑니다. 결과의 `cloud` 값으로 확인할 수 있습니다:
  `ok`(넣음) · `not-configured`(키 없음) · `no-student`(원생관리에 그 이름 없음) · `same-name`(동명이인) · `error: …`

### 처음 한 번 — 클라우드 키 넣기

1. supabase.com → 원생관리 프로젝트 → Project Settings → API Keys
   → **secret 키**(또는 Legacy 탭의 `service_role` 키)를 복사합니다.
2. dash.cloudflare.com → Workers & Pages → hello-world → Settings → Variables and Secrets
   → Add → 종류 **Secret**, 이름 `SUPABASE_SERVICE_KEY`, 값에 붙여 넣고 Deploy.
3. `https://hello-world.a28008005.workers.dev/api/health` 에서 `"hasStaffCloud":true` 가 보이면 끝입니다.

이 키는 학원 클라우드 전체를 열 수 있는 키입니다. 워커 비밀값에만 넣고, 앱 코드·카톡·문서에는 절대 붙이지 마세요.

## 고래 포인트 (마켓데이·고래카드)

보카 앱 코인(꾸미기·게임용)과 **따로** 셉니다. 진짜 돈으로 바꾸는 포인트라 학생 기기가 아니라 워커가 계산합니다.

| 규칙 | 값 |
|---|---|
| 하루 학습(오늘 항해) 완료 | 8P |
| 그날 정답률 90% 이상 | +2P |
| 7일 연속 완료 (7·14·21…일째) | +10P |
| 하루에 받는 횟수 | 1번 (같은 날 복습을 더 해도 안 늘어남) |
| 한 달 최대 | 300P = 3,000원 |
| 환산 | 1P = 10원 |

- 하루치를 끝낸 성적이 올 때, 그 학생의 **코드까지 맞아야** 포인트를 줍니다. 이름만으로는 안 줍니다.
- 원생관리 클라우드에 `kind: point` 한 줄로 남습니다. id는 `pt-학생번호-날짜`라 같은 날 두 번 와도 한 줄입니다.
- 원생관리 **고래 포인트** 화면에서 원장님이 [사용 · 빼기]를 누르면 음수 줄이 생기고, 앱 화면의 잔액도 줄어듭니다.
  원장님이 빼거나 직접 적립한 포인트는 한 달 최대 300P 계산에 들어가지 않습니다.
- 원생관리 명부에 같은 이름이 하나만 있어야 포인트가 쌓입니다 (성적 전달과 같은 조건).
- 숫자를 바꾸려면 `hello-world.js` 의 `POINT_RULES` 와 원생관리 `assets/js/store.js` 의 `POINT_RULES` 를 **같이** 바꿉니다.

## AI 튜터 (문장 카드 말하기) — `/api/tutor/turn`

학생 화면: `https://a28008005-sketch.github.io/dailytest/tutor/` (레벨을 정해서 열기: `?lv=240&v=1&u=1`)

- 아이가 카드 문장을 말하면 앱이 음성 인식 글자를 보내고, 워커가 AI에게 채점을 맡겨
  `correct`(맞음) · `almost`(거의) · `retry`(다시)와 짧은 한국어 한마디를 돌려줍니다.
- **원생 코드가 맞아야만** AI를 부릅니다. 코드가 없거나 퇴원생이면 사용료가 나가지 않습니다.
- 정답과 똑같이 말하면 앱이 기기에서 바로 칭찬하고 **AI를 부르지 않습니다**(빠르고 무료).
  틀렸거나 애매할 때만 AI를 부릅니다. 정답을 보여 준 뒤 따라 말하기도 기기에서만 확인합니다.
- AI가 안 되면(열쇠 없음·인터넷 끊김) 앱이 단어 비교로 대신 채점해서 공부는 그대로 이어집니다.
- 쓰는 AI: `TUTOR_MODEL` (지금 `claude-opus-5-5`, 생각 깊이 `low`). 바꾸려면 이 한 줄만 고치면 됩니다.

### 처음 한 번 — AI 열쇠 넣기

1. console.anthropic.com → API Keys → **Create Key** 로 열쇠를 만들고 복사합니다.
   (Billing에서 결제 수단을 등록하고, **Limits에서 월 사용 한도**를 꼭 정해 두세요)
2. dash.cloudflare.com → Workers & Pages → hello-world → Settings → Variables and Secrets
   → Add → 종류 **Secret**, 이름 `ANTHROPIC_API_KEY`, 값에 붙여 넣고 Deploy.
3. 아래 '바꾸는 법'대로 새 `hello-world.js` 를 올립니다.
4. `https://hello-world.a28008005.workers.dev/api/health` 에서 `"hasTutorKey":true` 가 보이면 끝입니다.

이 열쇠도 워커 비밀값에만 넣고, 앱 코드·카톡·문서에는 절대 붙이지 마세요.

## 바꾸는 법

1. dash.cloudflare.com → Workers & Pages → hello-world → Edit code
2. 코드를 모두 지우고 `hello-world.js` 내용을 붙여 넣은 뒤 **Deploy**

확인: `node worker/hello-world.test.mjs` · `node worker/tutor.test.mjs` (가짜 노션·가짜 클라우드로 로그인·진도·대시보드·성적 전달을 확인합니다)
