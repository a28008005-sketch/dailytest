웨일리 보카 설치 안내

고래영어 스마트 단어장을 휴대폰·태블릿에 앱으로 설치하는 방법

웨일리 보카를 아이 휴대폰이나 태블릿에 설치해 두시면, 홈 화면의 고래 아이콘만 눌러 바로 단어 공부를 시작할 수 있습니다.

앱스토어를 거치지 않는 방식이라 따로 가입하거나 결제하실 것은 없습니다. 공부한 진도는 학원 서버에 저장되기 때문에, 학원 태블릿에서 하던 공부를 집에서 이어서 할 수 있습니다.

1. 앱 주소 열기

휴대폰 카메라로 QR 코드를 비추시거나, 아래 주소를 눌러 주세요.

a28008005-sketch.github.io/dailytest/voca

카카오톡으로 받은 링크라면, 카카오톡 안에서는 설치가 되지 않습니다. 오른쪽 위 ⋮(또는 공유) 메뉴에서 다른 브라우저로 열기를 눌러 주세요.

2. 안드로이드 휴대폰·태블릿 (갤럭시 등)

  1. 크롬이나 삼성 인터넷으로 주소를 열어 주세요.
  2. 번호 화면 아래의 📲 이 기기에 앱으로 설치하기를 눌러 주세요.
  3. 설치 창이 뜨면 설치를 눌러 주세요. 홈 화면에 고래 아이콘이 생깁니다.

버튼이 보이지 않으면 브라우저 오른쪽 위 ⋮ 메뉴에서 앱 설치 또는 홈 화면에 추가를 눌러 주셔도 됩니다.

3. 아이폰·아이패드

  1. 반드시 사파리(Safari)로 주소를 열어 주세요.
  2. 공유 버튼(네모에 위쪽 화살표)을 눌러 주세요. 아이폰은 화면 아래쪽, 아이패드는 위쪽에 있습니다.
  3. 목록을 올려서 홈 화면에 추가를 누른 뒤, 오른쪽 위 추가를 눌러 주세요.

4. 처음 들어갈 때 — 부모님 휴대폰 번호 뒤 4자리

앱을 열면 번호 화면이 나옵니다. 부모님 휴대폰 번호 뒤 4자리를 눌러 주세요. 학원에서 출석할 때 쓰는 번호와 같습니다.

5678

예) 010-1234-5678 이라면 5678

형제·자매가 함께 다니는 경우에는 번호를 누른 뒤 아이 이름을 고르면 됩니다. 한 기기를 여러 아이가 함께 쓸 때는 화면 왼쪽 아래 학생 바꾸기를 눌러 주세요.

번호를 눌러도 들어가지 않으면 학원에 등록된 연락처가 다를 수 있습니다. 학원으로 알려 주시면 바로 확인해 드리겠습니다.
