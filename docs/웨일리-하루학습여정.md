# 웨일리 보카 — 하루 학습 여정 (단어 + 문장 통합)

스마트 단어장(단어)과 Sentence Bank(문장 카드)를 **하루 한 줄의 학습 길**로 합쳤습니다.
아이는 [오늘 항해 시작] 한 번만 누르면 아래 네 단계를 끊김 없이 지나 보물(코인)까지 갑니다.

```
🎧 STEP 1 오늘의 진도 → 🔁 STEP 2 랜덤 복습 → 🧩 STEP 3 문장 만들기 → 🎯 STEP 4 오답 클리어 → 🎁 보물
```

---

## 1. 왜 합쳤나 — 예전 구조와 비교

| | 예전 (따로) | 지금 (하루 한 길) |
|---|---|---|
| 들어가는 곳 | 홈에 [오늘 항해]와 [문장 만들기] 두 입구 | 입구 하나, 단계는 앱이 이어 줌 |
| 문장 카드 | 단어를 끝낸 뒤 리포트에서 **원하면** 누름 → 대부분 건너뜀 | STEP 3 필수 단계. 오늘 단어가 나온 교재 카드로 바로 이어짐 |
| 틀린 문장 | 카드 안에서만 다시 나오고 기록에 안 남음 | STEP 4 오답 클리어에 **단어 블록 배열**로 다시 나옴, 리포트·원생관리에 남음 |
| 끝나는 조건 | 단어 오답을 다 맞혀야 끝 → 어려운 문제에 묶여 포기 | 오늘 정답률(STEP 1~3) **80%** 면 보물. 못 넘어도 오답 클리어 3회차 뒤 끝 |
| 선생님이 보는 것 | 단어 성적만 | 단계별 진행(학습 중·멈춤·완료)과 문장까지 합친 정답률 |
| 품사 | 고학년 문장 문제에서만 가끔 | STEP 1 단어 화면마다 **색깔 품사 태그** (명사·동사·형용사·부사) |

**효과가 기대되는 이유**

- **완주율** — 화면을 옮길 때마다 아이가 빠져나갈 기회가 생깁니다. 입구를 하나로 묶고 다음 단계 버튼만 남기면
  "어디까지 해야 끝인가"가 지도(징검다리 4개 + 보물)로 보여서 끝까지 갈 동기가 생깁니다.
- **기억 유지** — STEP 1에서 익힌 단어를 같은 날 STEP 3 문장 속에서 다시 꺼내 쓰는 것이 *인출 연습*입니다.
  STEP 2의 지난 단어 10개 복습(간격 반복)과 합쳐, 하루에 같은 단어를 서로 다른 모양으로 세 번 이상 만납니다.
- **문법 감각** — 빈칸이 주어·동사·목적어 덩어리 단위로 뚫리고, 맞힌 뒤에는 문장을 색깔 성분으로 나눠 보여 줍니다.
  STEP 1의 품사 색과 같은 생각(이 말은 무슨 일을 하나?)을 문장 수준에서 이어 갑니다.
- **포기 방지** — 다 맞혀야 끝나는 구조는 약한 아이일수록 오래 걸립니다. 80% 기준 + 3회차 상한으로
  하루 학습 시간이 예측 가능해지고, 남은 오답은 리포트에 정직하게 남깁니다.

## 2. 단계별 내용

| 단계 | 하는 것 | 데이터 |
|---|---|---|
| STEP 1 오늘의 진도 | 듣고 고르기 · 말하기(음성 인식) · 뜻 고르기 · 영영 정의 · 빈칸 · 문장 배열. 단어에는 **품사 태그** | `#db` 의 오늘 Day 항목. 단어 `pos` 필드 |
| STEP 2 랜덤 복습 | 지난날 익힌 것 중 10개를 한 문제씩 | `progress.mastered` |
| STEP 3 문장 만들기 | 사진 카드 → 질문 듣기 → 빈칸(성분 한 덩어리) 채우기 → 주어/동사 찾기 → 색깔 성분 보기. 틀린 카드는 맨 뒤에 한 번 더 | `../cards/cards.js` 의 오늘 Unit·Day 카드 (240~1680) |
| ↳ 카드가 없을 때 | 파닉스 레벨, 또는 카드를 못 불러오면 **오늘 배운 문장을 단어 블록으로 배열** | `#db` 오늘 문장 |
| STEP 4 오답 클리어 | STEP 1~3에서 틀린 것만. 문장 카드에서 한 번에 못 만든 문장도 블록 배열로 다시 | `session.wrongs` |
| 🎁 보물 | 코인 → [웨일리 꾸미기] 상점, 리포트, 다음 Day 열림 | `progress.coins` |

**통과 규칙** (`PASS_PCT = 80`, `MAX_CLEAR_ROUNDS = 3`)

- 오늘 정답률 = (STEP 1~3에서 푼 문제 수 − 아직 남은 오답 수) ÷ STEP 1~3에서 푼 문제 수
- STEP 3이 끝난 뒤부터 80% 이상이면 [🎁 오늘 학습 완료 · 보물 받기]와 [남은 오답 더 도전하기]를 고를 수 있습니다.
- 80% 미만이면 STEP 4로 갑니다. 오답이 0개가 되거나 3회차를 마치면 끝납니다.

**품사 태그** — 단어 3,000여 개에 미리 붙여 두었습니다(파닉스 제외).
교재 문장 데이터에 품사가 적힌 단어는 그대로 쓰고, 나머지는 영어 사전(WordNet)이 허용하는 품사 중
한글 뜻 모양(…다 → 동사, …한/…운/…의 → 형용사, …에서/…로 → 부사)과 맞는 것만 붙였습니다.
교재에 품사가 적힌 단어로 확인했을 때 95% 일치했고, 둘이 맞지 않는 단어나 여러 단어로 된 표현은
태그를 **붙이지 않았습니다**(틀린 품사를 보여 주는 것보다 안 보여 주는 편이 낫기 때문).

## 3. 화면 구성 (컴포넌트)

```
App ─ 상태: profile · progress · view · session
 ├─ Home ─ Trail (징검다리: STEP 1~4 + 보물, 웨일리가 지금 위치에)
 ├─ Play          STEP 1 · 2 · 4, 그리고 카드 없는 STEP 3   (beats 배열을 한 문제씩)
 │    ├─ HUD: 진행 점·거리·콤보·점수, 바다 친구 말풍선(정답엔 환호, 오답엔 응원)
 │    └─ 문제 화면 ─ PosTag (단어 품사 색 태그)
 ├─ SentenceBuilder (embedded)   STEP 3 사진 카드
 │    card → build(빈칸) → parse(성분) ; 연속 정답 콤보·코인·축하 효과
 ├─ StageEnd      단계 끝: 정답률·코인·다시 볼 항목, 오늘 정답률(STEP 3부터), 다음 버튼
 ├─ ReportView    보물: 오늘 결과 · 코인
 └─ Shop          웨일리 꾸미기
```

## 4. 하루 학습 상태 흐름 (실제 코드 기준)

```
home ──[오늘 항해 시작]──▶ play(stage 1) ──onEnd──▶ stageend
stageend(1) ──▶ play(stage 2) ──▶ stageend
stageend(2) ──▶ startSentence
                 ├ 카드 있음 ─▶ sentence(SentenceBuilder) ──onStepDone──▶ stageend(3)
                 └ 카드 없음 ─▶ play(stage 3, 문장 배열)   ──onEnd──────▶ stageend(3)
stageend(3·4) ── 오답 0 또는 4단계 3회차 끝 ─────────────▶ finish ─▶ report(보물)
              ├─ 오늘 정답률 ≥ 80% ─ [보물 받기] ─────────▶ finish
              │                    └ [오답 더 도전] ─┐
              └─ 그 밖 ──────────────────────────────┴─▶ goClear ─▶ play(stage 4, round+1)
어느 화면이든 [나가기] ─▶ home  (원생관리에 '중간에 멈춤' 보고)
```

`session` 이 들고 있는 것:
`stage(1~4) · round · built(문제 목록) · stats[](단계별 결과) · wrongs[](남은 오답: item+type) · mastered[] · startedAt`

진행 상황은 단계가 시작·끝날 때와 5문제마다 워커로 보내고(`status: in-progress`), 원생관리
**단어 학습 → 오늘 실시간 현황**에 바로 나타납니다. 노션에는 끝낸 성적만 들어갑니다.
