# 슈퍼노바 학습방 만들기

본사 교재자료실(englishwhale.com)의 슈퍼노바 자료를 아이들이 태블릿·휴대폰에서
바로 넘겨 볼 수 있는 앱(`/nova/`)으로 바꾸는 프로그램입니다.

## 들어가는 자료
| 책 | 리딩 노트 | 구문 분석 PPT | 문장(해석) | 단어 |
|---|---|---|---|---|
| Supernova 1~4 | 지문별 | 문장별 → 지문에 배치 | 해석 엑셀 | 단어 엑셀(묶음별) |
| Supernova PLUS 1~2 | 지문별 | 지문 3개 묶음 → 지문에 배치 | 문장정리 | 지문별 단어 |

Grammar Map은 학생도 보고, **Grammar Map 정답은 선생님 비밀번호로만** 열립니다.
Answer Key·Final Test·Listening Test는 넣지 않았습니다.

## 잠금
교재 그림과 글은 모두 암호화되어 올라갑니다. 저장소가 공개라도 비밀번호 없이는 열리지 않습니다.
비밀번호는 이 저장소에 적지 않습니다.

## 다시 만들기
```
python3 -I convert.py <받은자료폴더> <작업폴더>      # PPT → 슬라이드 그림 (문제/정답 2장)
python3 -I build.py <받은자료폴더> <작업폴더> ../../nova <학생비번> <선생님비번>
```
비밀번호만 바꿀 때도 build.py를 다시 돌리면 됩니다. 작업폴더의 keys.json을 지우지 않으면 그림 파일은 그대로 두고 잠금만 바뀝니다.
